# Tech Team Bravo Downloads

Free 2-page playbooks from [Tech Team Bravo](https://techteambravo.com), IT and HIPAA support for medical practices and small businesses on Long Island, NY.

The best place to get them is the resource library: https://techteambravo.com/downloads/

This repository is the staging area the website automation uses to move finished PDFs into WordPress without changing a single byte. Please do not edit the PDFs here by hand.

- `healthcare/` playbooks for medical practices
- `business/` playbooks for small businesses
